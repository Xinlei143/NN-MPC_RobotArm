# Timing and Representative Figures

Four 500-plan calibrations selected D=6. Joint-only two-stage p95 was 46.24 ms;
task-space two-stage p95 was 52.28 ms; projection-off p95 was 49.90 ms; and
full-compiled p95 was 51.21 ms. Representative plots and a planner timeline
are included in the public evidence bundle.

The representative nominal circle case is the ThreadedASAP seed closest to the
median TCP RMSE (seed 3; 28.28 mm). All methods use the same trajectory and
seed for the representative comparison.
